# 生命线工程设备测试数据分析软件 V1.0 软件测试报告

## 1. 测试目标
验证软件核心算法在样例数据上的可运行性与结果完整性，形成可复核的文本化提交材料。

## 2. 测试环境
- 时间：2026-04-27
- 环境：Linux 容器，Python 3.10.19
- 数据集：`test_data.csv`、`data/def.csv`

## 3. 测试项
1. 数据完整性检查（行数、缺失值）。
2. 温度-位移相关性与线性回归计算。
3. SARIMA 趋势建模与 24h 预测。
4. 温度序列 GMM 统计建模。

## 4. 测试结果摘要
详见 `test_outputs/test_summary.json`，关键结果：
- 样本数：1000
- 温度-位移相关系数：0.8367
- 线性回归 R²：0.7000
- SARIMA AIC：4575.287
- GMM 双峰权重约：0.495 / 0.505

## 5. 环境限制
直接导入 GUI 主程序 `main.py` 时，因当前环境缺少 `libGL.so.1`，无法初始化 PyQt5 图形依赖；该问题属于运行环境依赖限制，不影响脚本级算法验证结论。

## 6. 结论
在无界面模式下，软件核心分析链路可稳定运行，满足 V1.0 对统计分析、相关性分析与趋势预测的功能要求。
