# 生命线工程设备测试数据分析软件 V1.0 软件设计文件

## 1. 总体设计
系统采用“数据层-算法层-展示层”分层设计：

1. **数据层**：负责 CSV/Excel 读取、时间字段标准化与结构转换。
2. **算法层**：负责异常值处理、统计分析、相关性回归、趋势预测。
3. **展示层**：负责 GUI 交互与图表展示、结果导出。

## 2. 模块设计
### 2.1 界面模块
- `main.py`：主界面、分析流程编排与图表承载。
- `login_window.py`：登录界面与入口管理。

### 2.2 算法模块
- `OutlierDetection`：缺失值补全与迭代异常检测。
- `CorrelationAnalysis`：线性回归与相关性结果输出。
- `StatisticalAnalysis`：基础统计与混合高斯建模。
- `PowerSpectrumAnalysis`：频域分析（Welch + 可选带通滤波）。

### 2.3 脚本模块（others）
- `others/correlation analysis.py`：相关性分析与可视化。
- `others/stats.py`：统计分析与 GMM 图示。
- `others/trend.py`：SARIMA 趋势建模与预测。

## 3. 关键流程设计
1. 数据导入与时间解析。
2. 数据清洗与异常处理。
3. 分析建模（统计/相关性/预测）。
4. 图形与结果文件输出。

## 4. 接口与输入输出
- **输入**：`test_data.csv`、`data/def.csv` 等监测样例。
- **输出**：`test_outputs/test_summary.json`、`test_outputs/stats_input.csv`、分析图（可本地再生成）。

## 5. 设计约束
1. GUI 运行依赖图形环境与 OpenGL 库。
2. 在无图形环境下应优先使用脚本方式执行算法验证。
